# Third-party and upstream attribution

Reinforced Minecarts is an independent community companion mod.

The Minecarts module integrates with the Reinforced Storage APIs and uses Reinforced Chests/Core as
dependencies. This repository includes source snapshots of the Build 14 community-port versions of
Reinforced Chests and Reinforced Core under `vendor/` so the 1.0.0 source tree remains reproducible.

Those vendor modules are derived from Aton-Kish's MIT-licensed Reinforced Storage projects. The
original Aton-Kish copyright notice is retained in this repository's MIT license.

Upstream:
- https://github.com/Aton-Kish/reinforced-chests
- https://github.com/Aton-Kish/reinforced-core

Community 26.2 port used by this release:
- https://github.com/mavrikakis9099-boop/reinforced-storage-26-2-community-port
